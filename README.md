# SO 101 Surgical Robot Controller

## Objective

The SO-101 robotic arm has the capability to grasp objects and manouvre in 6 degrees of freedom. This codebase is a controller for this robotic arm and enables an engineer to model a surgical insertion through the application of computer vision and robotic controller software.

The specific outcome for this project is to enable an SO-101 arm to reliably pick up a push pin, insert it into secured cardboard, and return to ahome position. Through this process, measurements, tracking, and analytics will enable us to understand effectiveness of this robotic arm at this task as well as the common failure points in high dexterity manipulation of objects in a surgical context.
